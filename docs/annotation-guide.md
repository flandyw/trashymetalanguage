# trashymetalanguage — passage annotation guide

Generated by `bun scripts/gen-guide.ts`. Every passage is a short text plus a human-written **answer key** (the `gold` spans) and **classification** fields. The app grades learners against this key, so errors in it teach the wrong metalanguage. The reference is **VCE English Language, VCAA study design 2024–2028**.

## 1. Passage schema

```ts
{
  id: 'u3s-01',                // unique across the whole app; use your bank's prefix
  title: 'Short descriptive title',
  text: 'The passage itself.',  // transcripts: one turn per line, "Speaker: words"
  source: 'Constructed: group chat between two friends',
  unit: 3,                     // 1 | 2 | 3 | 4 — the unit this passage best serves
  areaOfStudy: 'u3-informality',// must belong to that unit (list below)
  textType: 'personal-exchange',// one of the text types below
  mode: 'written',             // 'written' | 'spoken' | 'multimodal'
  field: 'weekend plans',      // subject matter / activity (short phrase)
  tenor: 'close friends; low social distance, informal',
  setting: 'private group chat, evening, real time',
  register: 'informal-register',// 'formal-register' | 'informal-register' | 'neutral-register'
  registerNote: 'One sentence justifying the register with evidence from the text.',
  dominantFunction: 'phatic',  // referential | emotive | conative | phatic | metalinguistic | poetic
  secondaryFunctions: ['emotive'], // optional; other functions clearly present
  functionNote: 'One sentence of evidence for the dominant function.',
  dominantSentenceType: 'declarative', // declarative | interrogative | imperative | exclamative
  sentenceStructure: 'simple-sentence', // simple-sentence | compound-sentence | complex-sentence | compound-complex-sentence | fragment
  transcript: true,            // only for multi-turn spoken transcripts
  lengthTier: 3,               // 0 single word; 1 phrase/one short sentence; 2 two-three sentences; 3 paragraph or transcript
  difficulty: 2,               // 1 (easy) .. 5 (hard)
  gold: [ { feature: 'slang', spans: ['sus'], note: 'Why this is an example, in one sentence.' } ],
  quiz: [ { prompt: '…', options: ['A', 'B', 'C', 'D'], answer: 2, explain: '…' } ],
  teach: 'One or two sentences of takeaway for the learner.',
}
```

## 2. Writing the answer key (`gold`)

1. **A span is an exact substring of `text`** (case-insensitive, apostrophes ' and ’ equivalent). It must start and end on a word boundary. **Every occurrence** of the substring in the passage is marked, so only use a span if *every* occurrence in the passage is a genuine example. If "that" is a subordinator once and a demonstrative once, do not use the bare span "that": use a longer span ("that the plan failed") or drop it.
2. **Do not put punctuation at the edges of a span** (except when the punctuation is part of the unit, e.g. `(.)`, `((laughs))`, `[yeah]`, `no:::`).
3. **One gold group per feature per passage.** If a feature has several examples, list them all in `spans` of one group. The validator rejects duplicate groups.
4. **Sub-word features** (prefix, suffix, infix, root, inflectional/derivational morpheme, backformation, shortening, hypocoristic…): use the **whole word** containing the morpheme as the span and name the morpheme in the note ("the prefix un- negates believable"). Never use a fragment such as "un" — it cannot be found as a whole word.
5. **Multi-word features** (phrases, clauses, idioms, phrasal verbs, adverbials, antithesis…): use the full unit as one span ("spill the beans"). A multi-word span is found by clicking any word inside it.
6. **Be selective, not exhaustive.** A good answer key has 5–12 feature groups for a paragraph, each with 1–8 occurrences (max 10). Do not annotate every noun or every determiner. Choose the features that a VCE examiner would expect a student to identify in this text, spread across at least three subsystems where the text allows.
7. **Prefer features listed for the passage's unit** (units are shown in the reference below). The validator warns when a feature is not listed for the unit; unit 3/4 passages may still use word classes and syntax (listed for all units).
8. **Use only feature ids from the reference in section 5.** Features marked *(text)* describe a whole text and are not allowed in `gold`.
9. Every gold group needs a one-sentence `note` that explains **why** using VCE metalanguage and evidence from the text. The note is shown to the learner after the hunt; make it teach.
10. Check your own work: the span must truly be that feature **in context** and under the **study design's definitions** (see reference). Typical traps: calling a possessive pronoun a pronoun *and* a determiner; calling every "-ing" word a verb; labelling a clipping as a blend; labelling metaphors that are dead metaphors; marking "like" as a simile when it is a discourse marker; labelling "nominalisation" for any noun.

## 3. Classifying the whole text

- **field**: the subject matter or activity (what is going on). **tenor**: relationship of participants, social distance and formality. **mode**: speaking / writing / multimodal. **setting**: time, place and medium. Together with text type, these are the *situational context*. Write short noun phrases, not sentences.
- **dominantFunction** uses Jakobson's six functions, with the study design's names: referential (informs, e.g. "The train leaves at 6.00 am"), emotive (feelings, e.g. "Yuck!"), conative (engages/directs the addressee, e.g. "Sit down!"), phatic (social connection, e.g. "How are you?"), metalinguistic (talks about language, e.g. "What does phatic mean?"), poetic (aesthetic form, e.g. "To be, or not to be?"). Pick the function that best explains the text's **main purpose**; list other clearly present ones in `secondaryFunctions`. Advertising is usually conative (+ poetic/emotive); news reports referential; greetings and small talk phatic; slogans poetic; a dictionary entry metalinguistic. The name "expressive" is **not** used; use emotive.
- **register**: formal / informal / mid-formal (`neutral-register`). Justify with linguistic evidence (contractions, colloquial lexis, nominalisation, passive voice, sentence length, etc.).
- **dominantSentenceType** and **sentenceStructure** describe the *most characteristic* sentence in the passage.
- **mode** must be exactly `written`, `spoken` or `multimodal`. Put any detail ("broadcast, scripted") in `setting`.
- Choose `unit` and `areaOfStudy` by what the passage is *best for*: e.g. an informal group chat → unit 3 `u3-informality`; a child-language transcript → unit 1 `u1-acquisition`; an extract showing prescriptivist attitudes to change → unit 2 `u2-english-across-time`; a text showing an ethnolect or code switching → unit 4.

## 4. Quiz questions

- 1–3 questions per passage, each answerable from the passage and the study design metalanguage, with 3–5 plausible, mutually exclusive options. Vary the position of the correct answer; do not always make it the first or the second option.
- Test analysis, not trivia: "Which word-formation process…?", "What is the function of the question in line 3?", "Which politeness strategy does Sam use?".
- `explain` must say why the answer is right and why the nearest distractor is wrong, citing the text.
- Never use "all of the above", "none of the above" or "both A and B".

## 5. Content and tone rules

- Texts must be **original or public domain**. Do not copy modern copyrighted text. Say honestly in `source` when a text is constructed ("Constructed:" prefix) or give the real public-domain source and date.
- Keep texts natural and contemporary-sounding where the unit is about contemporary language; for Unit 2 historical texts, use authentic public-domain material (e.g. Chaucer, Shakespeare, the 1611 King James Bible, Caxton, Johnson's Dictionary) quoted accurately, or clearly marked modern-English paraphrases.
- Aboriginal and Torres Strait Islander languages and Englishes: use only well-documented, publicly shareable vocabulary and features (e.g. *deadly*, *mob*, *yarn*, *gammon*, *sista*, *brother*, *shame*); never invent words or sentences "in an Aboriginal language"; never use sacred or restricted material; avoid caricature. Prefer texts **about** the varieties (public statements, interviews, opinion pieces, language-centre announcements) alongside natural conversation.
- Migrant ethnolects and other varieties: portray speakers as skilled, not as caricatures; avoid mock spellings; code switching should be plausible and respectful.
- No real people's private details, no defamatory content about real people. Swearing/taboo language may appear when the unit demands it (Unit 3 informality), mild (bloody, crap, hell, shit, piss off); no slurs.
- Spelling: Australian English (colour, organisation, program).

### Transcription conventions (for `transcript: true` passages)

One turn per line, written `Speaker: words`. Speaker labels are short capitalised names or roles (`Mia:`, `Interviewer:`). Use only these symbols:

- `(.)` — micropause (under one second)
- `(2.0)` — pause timed in seconds
- `[ ]` — overlapping speech
- `=` — latching: no gap between turns
- `:::` — lengthened sound
- `—` — abrupt cut-off or false start
- `CAPS` — louder speech or heavy stress
- `°word°` — quieter speech
- `>word<` — faster speech
- `↑ ↓` — rising or falling pitch
- `(( ))` — paralinguistic or non-verbal comment
- `(word)` — uncertain transcription

Pauses `(.)` and `(2.0)`, and `((comments))`, are clickable tokens and may be gold spans (features `pause`, `vocal-effect`, `non-verbal`, `voice-quality`). Speaker labels are not clickable and cannot be gold spans.

## 6. Feature reference (the only valid gold ids)

Format: `id` — label — units — short definition. *(text)* = whole-text feature, not allowed in gold. ★ = named in the study design table.

### Context & function

**Functions of language**
- `referential` — Referential function — U1,3 — Conveys information about the world (Jakobson). *(text)* e.g. The train leaves at 6.00 am.; Melbourne is the capital of Victoria.
- `emotive` — Emotive function — U1,3 — Expresses the speaker’s feelings, attitude or desires (Jakobson). *(text)* e.g. Yuck!; Ugh, I’m absolutely exhausted.
- `conative` — Conative function — U1,3 — Engages the addressee and tries to influence what they do or think (Jakobson). *(text)* e.g. Sit down!; You must hand it in by Friday.
- `phatic` — Phatic function — U1,3 — Establishes or maintains a social connection (Jakobson). *(text)* e.g. How are you?; Anyway, see you later.
- `metalinguistic` — Metalinguistic function — U1,3 — Talks about language itself (Jakobson). *(text)* e.g. What does phatic mean?; Is it “data are” or “data is”?
- `poetic` — Poetic function — U1,3 — Brings in the aesthetic dimension; draws attention to the form of the message (Jakobson). *(text)* e.g. To be, or not to be?; Snap, crackle and pop.

**Register and tenor**
- `formal-register` — Formal register — U1,3 — Language variation by use: planned, explicit, more social distance. *(text)* ★ e.g. The Committee resolved to adjourn.
- `informal-register` — Informal register — U1,3 — Language variation by use: spontaneous, implicit, social closeness. *(text)* ★ e.g. Yeah nah, I’ll be there in a sec.
- `neutral-register` — Mid-formal register — U1,3 — Between formal and informal: standard grammar with a relaxed tone. *(text)* e.g. Here’s what you need to know before you book.

**Informal & formal vocabulary**
- `colloquialism` — Colloquial language — U3,4 — Informal words, phrases or sayings, often specific to a region. ★ e.g. no worries; heaps good; have a go
- `slang` — Slang — U3,4 — Very informal vocabulary; metaphorical, playful, vulgar or taboo; marks in-group membership. ★ e.g. sus; lowkey; cooked
- `jargon` — Jargon — U3,4 — Specialised language of a trade, profession or group, hard for outsiders to follow. ★ e.g. stakeholder engagement; ablation; offside trap
- `taboo-language` — Taboo language — U3,4 — Language that is socially proscribed as improper or unacceptable. ★ e.g. bloody; piss off
- `swearing` — Swearing — U3,4 — Deliberate or subconscious use of offensive or vulgar language, including expletives. ★ e.g. bloody hell; shit
- `double-speak` — Double speak — U3 — Deliberately ambiguous or evasive language that disguises or distorts meaning. ★ e.g. negative patient outcome; collateral damage
- `non-discriminatory` — Non-discriminatory language — U3 — Wording chosen to avoid stereotyping or excluding people. ★ e.g. chairperson; first responders; people experiencing homelessness
- `emoji-grapheme` — Emoticon, emoji or context-specific grapheme — U3 — A symbol or punctuation mark that carries extra meaning in context. ★ e.g. #blessed; @mia; :)
- `standard-english` — Standard English feature — U3,4 — Usage that follows the codified conventions of Standard (Australian) English. e.g. It is not possible to attend.

### Phonetics & phonology

**Phonological patterning**
- `alliteration` — Alliteration — U3 — Repetition of the same initial consonant sound in nearby words. ★ e.g. big bold brand; Fresh from the farm
- `assonance` — Assonance — U3 — Repetition of the same vowel sound in nearby words. ★ e.g. slow road home; sleep deep
- `consonance` — Consonance — U3 — Repetition of the same consonant sound within or at the end of nearby words. ★ e.g. pitter-patter; lost and blessed
- `onomatopoeia` — Onomatopoeia — U3 — A word whose sound imitates the thing it names. ★ e.g. buzz; crunch; splash
- `rhyme` — Rhyme — U3 — Words that match in their final vowel and following consonant sounds. ★ e.g. Once bitten, twice shy; Don’t be a fool, stay cool
- `rhythm` — Rhythm — U3 — A regular or patterned beat created by stressed and unstressed syllables. ★ e.g. Veni, vidi, vici; Stop. Drop. Roll.

**Prosodic features**
- `stress` — Stress — U1,3 — Extra prominence given to a syllable or word. ★ e.g. I wanted the RED one
- `volume` — Volume — U1,3 — How loud or soft the speech is. ★ e.g. STOP; °sorry°
- `tempo` — Tempo — U1,3 — The speed of speech. ★ e.g. no:::; >hurry up<
- `intonation` — Intonation and pitch — U1,3 — The rise and fall of pitch across an utterance. ★ e.g. You’re coming?↑; Really↓

**Connected speech processes**
- `assimilation` — Assimilation — U1,3 — A sound becomes more like a neighbouring sound. ★ e.g. handbag; ten bikes
- `vowel-reduction` — Vowel reduction — U1,3 — An unstressed vowel weakens towards schwa /ə/. ★ e.g. to; and; for
- `elision` — Elision — U1,3 — A sound is left out in connected speech. ★ e.g. dunno; gonna; ol’ man
- `insertion` — Insertion — U1,3 — An extra sound is added in connected speech. ★ e.g. law and order; filum

**Language acquisition**
- `child-phonological-process` — Child phonological process — U1 — A systematic simplification in a child’s pronunciation. ★ e.g. tar (star); nana (banana); wawa (water)

### Morphology

**Morphemes**
- `root` — Root — U1,2 — The core morpheme that carries a word’s main meaning. ★ e.g. happy in unhappiness; believe in unbelievable
- `free-morpheme` — Free morpheme — U1,2 — A morpheme that can stand alone as a word. ★ e.g. cat; doom; scroll
- `bound-morpheme` — Bound morpheme — U1,2 — A morpheme that cannot stand alone; it must attach to another. ★ e.g. un-; -ness; -ed
- `prefix` — Prefix — U1,2 — An affix attached before a root or stem. ★ e.g. un-; re-; dis-
- `suffix` — Suffix — U1,2 — An affix attached after a root or stem. ★ e.g. -ness; -able; -ing
- `infix` — Infix — U1,2 — An affix inserted inside another word. ★ e.g. abso-bloody-lutely; fan-bloody-tastic
- `inflectional-morpheme` — Inflectional morpheme — U1,2 — A bound morpheme that adds grammatical information without creating a new word. ★ e.g. -s; -ed; -ing
- `derivational-morpheme` — Derivational morpheme — U1,2 — A bound morpheme that creates a new word, often of a different word class. ★ e.g. -ness; -able; un-
- `morphological-overgeneralisation` — Morphological over-generalisation — U1 — Applying a regular rule to a word that is an exception. ★ e.g. goed; mouses; bringed

**Word formation processes**
- `abbreviation` — Abbreviation — U2,3,4 — A shortened written form of a word or phrase. ★ e.g. Dr; approx.; Mon.
- `shortening` — Shortening (clipping) — U2,3,4 — Cutting a word down to a shorter form with the same meaning. ★ e.g. uni; info; flu
- `compounding` — Compounding — U2,3,4 — Joining two or more free morphemes to form a new word. ★ e.g. doomscroll; screenshot; notebook
- `blending` — Blending — U2,3,4 — Fusing parts of two words into one new word. ★ e.g. brunch; podcast; hangry
- `backformation` — Backformation — U2,3,4 — Creating a new word by removing what looks like an affix from an existing word. ★ e.g. edit; burgle; babysit
- `conversion` — Conversion of word class — U2,3,4 — A word changes word class without any change in form. ★ e.g. to google; a big ask; to friend
- `initialism` — Initialism — U2,3,4 — An abbreviation pronounced letter by letter. ★ e.g. ATM; DIY; FAQ
- `acronym` — Acronym — U2,3,4 — An abbreviation formed from initial letters and pronounced as a word. ★ e.g. NASA; ATAR; NAPLAN
- `contraction` — Contraction — U2,3,4 — Two words merged into one, with an apostrophe marking the omitted letters. ★ e.g. don’t; we’re; it’s
- `hypocoristic` — Hypocoristic form — U4 — A shortened word or name with an added suffix (-ie, -o), giving a familiar tone. ★ e.g. mozzie; tradie; arvo

### Lexicology

**Word classes**
- `noun-common` — Common noun — U1,2,3,4 — A general name for a class of person, place, thing or idea. ★ e.g. teacher; river; justice
- `noun-proper` — Proper noun — U1,2,3,4 — The unique name of a particular person, place, brand or event. ★ e.g. Melbourne; VCAA; Mia
- `noun-abstract` — Abstract noun — U1,2,3,4 — A noun naming an idea, quality, state or feeling you cannot perceive with the senses. e.g. freedom; uncertainty; implementation
- `noun-concrete` — Concrete noun — U1,2,3,4 — A noun naming something perceivable by the senses. e.g. table; ute; tram
- `noun-collective` — Collective noun — U1,2,3,4 — A singular noun that names a group. e.g. team; committee; flock
- `pronoun` — Pronoun — U1,2,3,4 — A word that stands in for a noun or noun phrase. ★ e.g. she; they; we
- `pronoun-demonstrative` — Demonstrative pronoun — U1,2,3,4 — A pointing pronoun: this, that, these, those. e.g. this; those
- `determiner` — Determiner — U1,2,3,4 — A word that introduces and limits a noun phrase: the, a, my, some, every, three. ★ e.g. the; my; some
- `article-definite` — Definite article — U1,2,3,4 — The word ‘the’, marking a noun as already identified. e.g. the
- `article-indefinite` — Indefinite article — U1,2,3,4 — The words ‘a’ and ‘an’, introducing a noun not yet identified. e.g. a; an
- `verb-lexical` — Lexical (main) verb — U1,2,3,4 — A verb that carries the main meaning of the clause. ★ e.g. run; know; seem
- `verb-auxiliary` — Auxiliary verb — U1,2,3,4 — A helping verb (be, have, do) that works with a main verb for tense, aspect, voice or negation. ★ e.g. has; was; did
- `verb-modal` — Modal verb — U1,2,3,4 — A verb expressing possibility, obligation, ability, permission or prediction. ★ e.g. must; might; should
- `verb-semi-modal` — Semi-modal — U1,2,3,4 — A multi-word expression doing a modal job: have to, need to, be going to. e.g. have to; need to; be going to
- `verb-phrasal` — Phrasal verb — U1,2,3,4 — A verb plus a particle forming one unit of meaning (a multi-word lexeme). ★ e.g. switch off; give up; put up with
- `adjective` — Adjective — U1,2,3,4 — A word that describes or classifies a noun. ★ e.g. unbelievable; sustainable; cheeky
- `adjective-comparative` — Comparative adjective — U1,2,3,4 — An adjective form that compares two things: -er or more. e.g. faster; more reliable; better
- `adjective-superlative` — Superlative adjective — U1,2,3,4 — An adjective form that puts one thing above all others: -est or most. e.g. fastest; most trusted; best
- `adverb` — Adverb — U1,2,3,4 — A word that modifies a verb, an adjective, another adverb or a whole clause. ★ e.g. quickly; often; however
- `adverb-degree` — Intensifier (degree adverb) — U1,2,3,4 — Turns the volume up or down on an adjective or adverb. e.g. very; really; so
- `preposition` — Preposition — U1,2,3,4 — A word showing a relationship of place, time, direction or manner before a noun phrase. ★ e.g. in; on; under
- `preposition-complex` — Complex preposition — U1,2,3,4 — A multi-word preposition acting as one unit. e.g. in spite of; according to; on behalf of
- `conjunction-coordinating` — Conjunction (coordinator) — U1,2,3,4 — Joins items of equal rank: and, but, or, nor, so, yet, for. ★ e.g. and; but; or
- `conjunction-subordinating` — Conjunction (subordinator) — U1,2,3,4 — Introduces a dependent clause: because, although, when, if, since, while. ★ e.g. because; although; if
- `interjection` — Interjection — U1,2,3,4 — A short word or sound that stands alone to express emotion or reaction. ★ e.g. wow; ugh; oh

**Function words and content words**
- `function-word` — Function word — U1 — A word with mainly grammatical meaning: determiners, pronouns, prepositions, conjunctions, auxiliaries. ★ e.g. the; of; and
- `content-word` — Content word — U1 — A word with rich lexical meaning: nouns, lexical verbs, adjectives, most adverbs. ★ e.g. doomscroll; river; cheeky

**Word formation (lexical)**
- `neologism` — Neologism — U2,3 — A newly coined word or a new sense for an existing word. ★ e.g. doomscroll; selfie; hangry
- `borrowing` — Borrowing — U2,3 — A word taken from another language and adopted into English. ★ e.g. kindergarten; kangaroo; pizza
- `commonisation` — Commonisation — U2,3 — A proper noun (often a brand) becoming a common noun or verb. ★ e.g. esky; to hoover; band-aid
- `nominalisation` — Nominalisation — U2,3 — Turning a verb or adjective into a noun. ★ e.g. implementation; the decision; failure

**Word loss**
- `archaism` — Archaism — U2 — A word or form no longer in everyday use, kept for special effect. ★ e.g. thee; hath; whilst
- `obsolescence` — Obsolescence — U2 — A word that has fallen out of use altogether. ★ e.g. yclept; withal

### Syntax

**Phrases**
- `noun-phrase` — Noun phrase — U1,2,3,4 — A noun plus the determiners and modifiers that go with it. ★ e.g. the old tram; proposed changes to the policy
- `verb-phrase` — Verb phrase — U1,2,3,4 — A main verb plus any auxiliary or modal verbs. ★ e.g. might have been waiting; is running
- `adjective-phrase` — Adjective phrase — U1,2,3,4 — An adjective plus any modifiers or complements. ★ e.g. extremely proud of her team
- `adverb-phrase` — Adverb phrase — U1,2,3,4 — An adverb plus any modifiers. ★ e.g. very quickly; far too slowly
- `prepositional-phrase` — Prepositional phrase — U1,2,3,4 — A preposition followed by its noun phrase. ★ e.g. at the station; in spite of the rain

**Clauses**
- `clause` — Clause — U1,2,3,4 — A group of words built around a verb, usually with a subject. ★ e.g. she left; because it rained
- `subject` — Subject — U1,2,3,4 — The noun phrase that the clause is about, normally before the verb. ★ e.g. The committee; She
- `object` — Object — U1,2,3,4 — The noun phrase affected by the verb (direct) or receiving it (indirect). ★ e.g. a letter; him
- `predicate` — Predicate — U1,2,3,4 — Everything in the clause that is not the subject: the verb and what follows. ★ e.g. denied the claim; was tired
- `complement` — Complement — U1,2,3,4 — A phrase completing the meaning of a linking verb (subject or object complement). ★ e.g. a teacher; salty
- `adverbial` — Adverbial — U1,2,3,4 — A word, phrase or clause adding information about time, place, manner, reason or condition. ★ e.g. yesterday; at the station; because it rained
- `coordination` — Coordination — U1,2,3,4 — Joining clauses (or phrases) of equal status with a coordinator. ★ e.g. I rang and she answered
- `subordination` — Subordination — U1,2,3,4 — Making one clause depend on another using a subordinator or relative pronoun. ★ e.g. Although it rained; who called yesterday

**Sentence structures**
- `simple-sentence` — Simple sentence — U1,2,3,4 — One independent clause. *(text)* ★ e.g. The tram stopped.
- `compound-sentence` — Compound sentence — U1,2,3,4 — Two or more independent clauses joined by coordination. *(text)* ★ e.g. The tram stopped and the doors opened.
- `complex-sentence` — Complex sentence — U1,2,3,4 — An independent clause plus at least one dependent clause. *(text)* ★ e.g. When the tram stopped, the doors opened.
- `compound-complex-sentence` — Compound-complex sentence — U1,2,3,4 — Two or more independent clauses and at least one dependent clause. *(text)* ★ e.g. When the tram stopped, the doors opened and we stepped out.
- `fragment` — Sentence fragment — U1,2,3,4 — An incomplete sentence, often used deliberately for effect or in speech. *(text)* ★ e.g. Nope.; Fresh from the farm.

**Sentence types**
- `declarative` — Declarative sentence — U1,2,3,4 — A statement; subject comes before the verb. *(text)* ★ e.g. The tram is late.
- `interrogative` — Interrogative sentence — U1,2,3,4 — A question. *(text)* ★ e.g. Are you coming?
- `imperative` — Imperative sentence — U1,2,3,4 — A command or request, usually with no stated subject. *(text)* ★ e.g. Sit down.; Please take a seat.
- `exclamative` — Exclamative sentence — U1,2,3,4 — An exclamation, often introduced by what or how. *(text)* ★ e.g. What a day!; How lovely!

**Word order**
- `premodifier` — Premodifier — U1,2,3,4 — A modifier placed before the head noun in a noun phrase. ★ e.g. old stone; the proposed
- `postmodifier` — Postmodifier — U1,2,3,4 — A modifier placed after the head noun in a noun phrase. ★ e.g. over the creek; that collapsed

**Voice**
- `active-voice` — Active voice — U3,4 — The subject performs the action: ‘The council approved the plan.’ ★ e.g. The council approved the plan
- `passive-voice` — Passive voice — U3,4 — The subject receives the action: ‘The plan was approved by the council.’ ★ e.g. The plan was approved by the council
- `agentless-passive` — Agentless passive — U3,4 — A passive clause that omits who did the action. ★ e.g. Mistakes were made; The funds were misallocated

**Syntactic patterning**
- `antithesis` — Antithesis — U3 — Contrasting ideas placed in parallel structures. ★ e.g. Ask not what…; ask what…; Give me liberty or give me death
- `listing` — Listing — U3 — A sequence of items of the same grammatical kind, often three. ★ e.g. faster, safer, cheaper; blood, toil, tears and sweat
- `parallelism` — Parallelism — U3 — Repeating the same grammatical structure across phrases or clauses. ★ e.g. We shall fight on the beaches, we shall fight on the landing grounds

**Language acquisition**
- `holophrase` — Holophrase — U1 — A single word functioning as a whole utterance in early child language. ★ e.g. milk; up
- `telegraphic-speech` — Telegraphic speech — U1 — Child utterances that keep content words and omit function words and inflections. ★ e.g. Mummy go work; more juice; doggie eat

### Discourse & pragmatics

**Features of spoken discourse**

- `adjacency-pair` — Adjacency pair — U3,4 — Two turns by different speakers where the second responds to the first. ★ e.g. How are you? — Good, thanks; Thanks! — No worries

- `discourse-marker` — Discourse marker (particle) — U3,4 — A word or phrase that organises talk or signals the speaker’s stance. ★ e.g. like; you know; anyway

- `repair` — Repair — U3,4 — A correction or clarification of something just said, by the speaker (self-repair) or another (other-repair). ★ e.g. on Tuesday— sorry, Thursday; I mean

**Politeness strategies**
- `positive-politeness` — Positive politeness — U3,4 — A strategy that meets the addressee’s need to be liked and approved of. ★ e.g. mate; Great work, team!; We’ve got this
- `negative-politeness` — Negative politeness — U3,4 — A strategy that respects the addressee’s freedom from imposition. ★ e.g. Would you mind…?; Sorry to bother you
- `face-threatening-act` — Face-threatening act — U3,4 — An utterance that threatens the positive or negative face of speaker or addressee. ★ e.g. Do it now; That’s wrong
- `positive-face` — Positive face — U3,4 — The need to be liked, approved of and included. *(text)* ★ e.g. being praised
- `negative-face` — Negative face — U3,4 — The need for freedom of action and freedom from imposition. *(text)* ★ e.g. being left alone

**Cohesion**
- `anaphora` — Anaphoric reference — U3 — A word that points back to something already mentioned. ★ e.g. She… she; The council… it
- `cataphora` — Cataphoric reference — U3 — A word that points forward to something about to be mentioned. ★ e.g. Here is the plan:; This is what I mean:
- `deictic` — Deictic — U3 — A word whose meaning depends on the speaker, place or time of the utterance. ★ e.g. here; now; this one
- `cohesive-repetition` — Repetition (cohesion) — U3 — A key word or structure repeated deliberately to link a text. ★ e.g. freedom… freedom… freedom
- `substitution` — Substitution — U3 — Replacing a word or phrase with a stand-in such as ‘one’, ‘do so’ or ‘so’. ★ e.g. one; do so
- `ellipsis` — Ellipsis — U3 — Omission of words that can be recovered from context. ★ e.g. Want a coffee?; Love one.
- `cohesive-conjunction` — Conjunction or linking adverbial — U3 — A connective that signals the logical link between clauses or sentences. ★ e.g. however; therefore; in addition
- `collocation` — Collocation — U3 — Words that habitually occur together. ★ e.g. heavy rain; make a decision

**Information flow**
- `clefting` — Clefting — U3 — Restructuring a sentence to focus a particular element, typically with ‘it’ or ‘what’. ★ e.g. It was the budget that caused the delay; What we need is time
- `front-focus` — Front focus — U3 — Moving an element to the start of the clause to emphasise it. ★ e.g. Rubbish I can handle; Great, she was
- `end-focus` — End focus — U3 — Placing the most important or new information at the end of the clause. ★ e.g. …and the winner is Mia

**Coherence**
- `coherence` — Coherence — U3 — The sense that a text hangs together as a meaningful whole. *(text)* ★ e.g. logical ordering of paragraphs

### Semantics

**Meaning and sign**

- `multi-word-lexeme` — Multi-word lexeme — U1,2,3,4 — A sequence of words stored and retrieved as one unit of meaning. ★ e.g. spill the beans; switch off; ice cream

**Euphemism and dysphemism**

- `dysphemism` — Dysphemism — U3,4 — A deliberately harsh or offensive expression used instead of a neutral one. ★ e.g. croak; pig; bludger

**Semantic patterning**
